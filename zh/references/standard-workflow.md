# 从参考研究到共同定调（执行手册）

阶段一至五是默认共创流程，二至四可按反馈反复往返。遇到具体视觉难题且用户希望看效果时，可直接从阶段四进入阶段六做小规模试样，再回到搜图或整理。始终复用用户已提供的背景、偏好与授权，不重复发问。

---

## 阶段一：对齐起点与探索线索

1. **先读上下文**：从已有对话和项目文档中提取设计对象、受众、使用场景与硬约束，区分已知事实与 Agent 推断。
2. **极简补问**：仅当完全不知道“做什么、用在哪里、解决什么问题”时，提出 **1–3 个短问题**，等回复再开搜；如果用户明确只想开放找灵感，直接按开放探索推进。
3. **不逼用户先说风格**：用户说“不知道喜欢什么风格”正是本流程要解决的问题，不要要求用户先定字体、配色或专业风格名词。
4. **保留原话与线索**：
   - 从零开始：共同展开 2–4 组有反差的联想词（可来自年代、音乐、场景、材质或生活片段）。
   - 已有关键词：沿原词直搜，同时补充关联词供对照。
   - 已有参考图：优先追溯完整项目、创作者与系列应用，再扩展同类手法。
   - 已有具体问题：直接按问题建搜索路线（如“照片封面裁切”“深色背景字图层级”），无需先补全套品牌定位。

> 线索够启动搜索就直接开搜，不必再多问一句“现在可以开始了吗？”。

---

## 阶段二：高质量搜图与防图裂

### 1. 双语检索与多路线展开
- **中英/日双语扩展**：用户给中文感受词（如“温暖、粗粝、手工”）时，自动转为专业英文/日文设计词（如 `risograph editorial poster`、`tactile packaging typography`、`装丁 デザイン`、`editorial book design`），并把**用户原词**与 **Agent 扩展词**明确分开记录。
- **跨媒介覆盖**：除直接竞品外，按需跨到平面海报、书籍装帧、唱片封面、展览视觉、包装、空间摄影与网页交互中找手法，避免思路锁死在同类产品里。
- **同词多解**：每个核心词至少呈现 **2 种明显不同的视觉解释**，并可加入 1–2 个边界案例，帮助用户快速划出“喜欢 / 不想要”的边界。

### 2. 高审美信源优先级与去 AI 味过滤
- **优先信源**：真实设计工作室官网、Behance 完整项目、Are.na、Fonts In Use、It's Nice That、Brand New、Awwwards、Cosmos、ArchDaily、Read.cv、设计年鉴与独立出版物归档。
- **明确过滤**：避开 AI 生成图合集、千篇一律的通用素材模板站、低分辨率二次搬运拼贴图；绝不拿 AI 生成图冒充真实设计参考。
- **深入完整项目**：发现强参考时，优先点进完整项目页看系列延展和细节图，不停留在孤立缩略图。

### 3. 首轮体量与本地化防图裂
- **数量基准**：首轮默认收集 **15–30 张** 有效且有视觉差异的作品（范围很窄的具体问题可 10–15 张）；超过 24 张时在图库中按词或分页组织。如实记录本轮覆盖范围与搜索缺口。
- **稳定编号**：从 `I001` 起顺序编号，跨轮次、分组、页面和导出始终不变；同一作品可挂载多个关键词标签。
- **本地缓存防裂图**：很多设计站有防盗链，直接引外链极易在 HTML 里裂图。**优先将核验过的预览图下载到 `assets/` 目录并用相对路径引用**；无法下载或加载失败的链接标记为失效并折叠记录，不塞进主视图破坏体验。
- **状态分离**：每张图仅保留清晰状态：`候选` / `Agent 推荐` / `用户已选` / `已折叠（附原因）`。推荐不覆盖候选，未核验项如实标明。

## 阶段三：交付单文件交互图库

### 1. 默认交付形态：零依赖单文件 HTML
优先生成可直接双击打开的 `image-selection.html`（引用同级 `assets/` 本地图片，无需起后端服务，天然可携带、可分享）：
- **图片为主**：大尺寸清晰卡片，网格留白克制；卡片只显示 `编号 + 简短项目名 + 关键词标签 + 原项目外链`，长分析收进详情弹窗或 `notes.md`。
- **完整构图放大**：点击大图支持完整比例灯箱预览（禁止强制正方形裁切破坏原作构图），有系列图或细节图时可在灯箱内切换。
- **清晰视图与计数**：提供 `全部候选` / `本轮新增` / `Agent 推荐` / `用户已选` 视图切换 + 按关键词筛选 + 一键清除筛选；顶部实时显示 `当前数量 / 总数量` 及明确单位（如“24 张参考图 · 来自 14 个项目”）。折叠区可展开查看重复或失效记录。
- **低摩擦标注与一键导出**：支持点击标记 `喜欢 / 不符合 / 待比较` 及可选短评（自动暂存 `localStorage`）；页面固定显眼的 **「一键复制选图反馈」** 按钮，点一下即可复制标准化的 `编号 + 关键词 + 评价 + 短评` 文本，方便用户直接贴回对话。

> 只有在环境强制需要时才使用本地服务，且必须在启动命令返回后独立验证页面可持续访问、重启后选择不丢失，不把临时 `localhost` 当分享链接。

### 2. 交付检查与引导话术
- **先自检再交付**：确认图片无裂图、灯箱放大正常、编号与关键词对应无误、原链接可点、一键复制输出格式正确；无法验证的项如实说明。
- **带对比锚点交付**：不要只甩一个链接问“你喜欢哪张”。主动挑出 **2–3 组最有反差的图** 帮用户起头（例如：“同样搜‘粗粝手工’，`I004` 偏单色粗网点印刷，`I011` 偏暖白厚纸+大留白，你更靠近哪边？”）。
- **等待反馈**：用户回复前不替用户定调；必须真正读到用户的回复或粘贴的导出文本后再进入阶段四。

## 阶段四：Art Director 视角的看图拆解与补搜

从用户点名的编号或感受出发，**原样记录用户原话**，与 Agent 的专业拆解分开存放。

### 1. 五维视觉拆解清单
当用户只说“喜欢 `I012`”“`I007` 有点土”时，用以下 5 个具体维度帮用户把直觉翻译成可执行的视觉判断：
1. **字图关系**：字压图 / 图窗留白 / 满版出血 / 极细衬线 vs 粗黑标题的层级对比。
2. **色彩与对比**：低饱和纸感 / 高饱和撞色 / 黑白主调 + 单一专色点缀。
3. **材质与工艺**：粗网点印刷、纸张纤维、胶片颗粒、金属/玻璃反光、干净数字平涂。
4. **构图与裁切**：呼吸感留白、局部极近特写、对称仪式感、拼贴错位。
5. **系列延展性**：脱离这张完美摄影，换成普通产品图/多条信息时这套语言还能不能成立。

### 2. 按反馈路由下一步
- **有强锚点**：顺藤摸瓜深挖该作品的完整项目、创作者、同工作室案例或同类工艺，补搜验证理解。
- **多个方向都有感觉**：保留分歧，拆成 2 条平行路线分别补图对比，不急着强行合并。
- **只喜欢局部**：锁定那个单一特征（如“只喜欢它的标题比例，不喜欢配色”）跨风格找其他组合，避免整套照搬。
- **聚焦到具体执行问题**：围绕该问题补搜，或经用户同意直接进入**阶段六**做小批量对照试样。
- **全都不符合**：结合用户原话诊断是词义偏了、媒介不对还是太复古/太商业，修订关键词换路线重搜。
- **判断已足够清晰**：直接进入**阶段五**整理情绪板，无需多余的仪式性确认。

新增候选继续顺延编号，在图库中标出“本轮新增”及补搜原因，保留上一轮材料与反馈。

## 阶段五：沉淀情绪板

当用户选图与讨论已能清晰支撑 1 个或多个方向时（或用户明确授权代选时），整理情绪板：

1. **提炼方向**：共识一致做 1 张板，存在实质审美分歧则分成 2–3 张独立方向板并各自命名。
2. **以图为主、保真呈现**：围绕主导参考组织大图、局部细节与系列应用；不必把所有选图硬塞进板面，取舍理由写在记录里。如果拼贴会破坏作品比例与气场，直接用清晰的参考浏览页呈现。
3. **三段式说明**：每个方向只写精炼且有信息量的三句话链条——**参考中的关键手法 → 对本项目的转化启发 → 仍待验证的部分**。
4. **区分归属与保留回看**：Agent 为补齐执行细节而新增的桥梁参考必须标明归属；板面保留返回候选图库、词库与讨论记录的入口。

> 用户只要求情绪板时，在此交付并收尾；明确区分“参考方向已定”与“原创品牌/UI 已定稿”，不擅自展开全案。

## 阶段六：控制变量的真实素材试样（按需）

仅在用户明确需要试做、初稿、照片处理验证或界面方向对照时进入。试样是用来帮用户做判断的讨论材料，不自动等于定稿。

1. **诚实标注工艺来源**：区分“原作者公开工艺”、“Agent 提出的近似实现方案”与“对本项目素材的适用边界”；查不到原工艺标未知，不把数字滤镜写成还原原作工艺。
2. **两条核心对照轴**（先做小批量，不盲目穷举）：
   - **同图多法**：同一张真实素材，对比 2–3 种视觉处理或版式，看哪种气质最对。
   - **同法多图**：同一种看好的方法，套到 3–5 张不同明暗/构图/题材的真实素材上，测它是不是“只挑好图”。
3. **控制变量与分层展示**：多方向共用同一产品目标、真实文案池、画幅与核心功能，只改变布局、比例、裁切与处理方式。按需展示 `原始参考 → 项目原图 → 处理结果 → 最终构图`，便于快速定位问题出在素材、滤镜还是版式。
4. **独立编号与分离记录**：试样单独编号（如 `T001`）并关联对应参考编号（如 `from I012`）。**喜欢参考图 ≠ 接受试样的裁切、遮挡或字图关系**，两者分开记录。
5. **诊断迭代与交接**：效果偏离预期时，先诊断具体变量（色彩/材质/比例/信息层级/素材本身），下一轮只改关键变量再对照。方向经用户确认后，按需把验证通过的色彩角色、字图关系、图像处理与构图规则沉淀到 `visual-language.md` 供后续开发/设计交接。
