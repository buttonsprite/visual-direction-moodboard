# 交付物与记录模板

按需选用，不强求首轮建全所有文件。原则：**图库负责直观浏览与低摩擦反馈，Markdown 负责轻量追溯与跨轮次沉淀。**

---

## 一、轻量探索记录：`notes.md`（首轮默认）

首轮探索用一份 `notes.md` 合并背景、词库与讨论记录，减少文件碎片。

```markdown
# <项目名> · 视觉方向探索

## 1. 本轮起点
- **探索对象与场景**：
- **已知约束**：
- **用户原话与初始判断**：
- **本轮想看清什么**：

## 2. 词库与搜索路线
| 编号 | 用户原词 | Agent 扩展词（含英/日文） | 信源与覆盖 | 已知缺口 |
| --- | --- | --- | --- | --- |
| W01 | 温暖、粗粝、手工 | risograph editorial, tactile paper print | Behance, Are.na, Fonts In Use | 缺中文排版的同气质案例 |

## 3. 看图讨论与修订（按轮次追加）
### Round 1
- **用户选图与原话**：
  - `I004`（喜欢）：“字图比例很舒服，有呼吸感”
  - `I011`（不符合）：“颜色太暗，有点沉闷”
- **五维拆解（Agent 观察）**：
  - 字图关系：大面积留白 + 细衬线标题
  - 色彩主次：避免高浓度深棕，转向暖白纸底 + 清爽专色
- **下一步动作**：沿 `I004` 深入完整项目，补搜 8 张清爽配色的同版式参考（`I025`–`I032`）
```

## 二、单文件候选图库：`image-selection.html` 必备规格

优先输出零依赖单文件 HTML（图片放同级 `assets/` 目录），确保双击即开、不裂图、易分享：

### 界面与交互清单
1. **顶部栏**：项目名、当前视图切换（`全部候选` / `本轮新增` / `Agent 推荐` / `用户已选`）、关键词筛选胶囊、`清除筛选` 按钮、实时计数与单位（例：`显示 18 / 24 张参考图 · 来自 14 个项目`）。
2. **卡片区**：大图优先（保留比例或完整关键区域）、稳定编号（`I001`）、简短项目名、关键词标签、原项目外链图标、三个轻量状态按钮（`喜欢` / `待比较` / `不符合`）+ 可选单行短评输入框。
3. **灯箱详情**：点击图片弹出完整构图大图（无破坏性裁切），展示作品信息、来源链接、Agent 1 句视觉拆解、同项目系列图切换。
4. **折叠区**：底部可展开查看重复、失效或剔除的候选及原因，保持过程透明。
5. **悬浮导出条（核心）**：自动将标注存入 `localStorage`，右下角固定 **「一键复制选图反馈」** 按钮，点击后复制以下格式文本，方便用户直接贴回对话：

```text
【视觉参考选图反馈 · Round 1】
- 喜欢：
  - I004 [W01 温暖粗粝]：字图比例舒服，留白够
  - I012 [W02 纸感印刷]：喜欢纸张纹理，但不喜欢偏暗的配色
- 待比较：
  - I018 [W01 温暖粗粝]：
- 不符合：
  - I007 [W01 温暖粗粝]：太像通用模板
```

### 交付给用户的标准话术
```text
这轮围绕「<用户原词>」，扩展检索了 <英文/跨媒介路线>，共整理了 <N> 张真实设计参考（来自 <M> 个项目），已本地缓存防裂图。

👉 打开图库：<image-selection.html 路径>

建议先对比这 2–3 组反差案例：
1. <I00X> vs <I00Y>：<一句话点出核心视觉手法差异>
2. <I00A> vs <I00B>：<一句话点出核心视觉手法差异>

你可以在页面里直接点选「喜欢 / 不符合 / 待比较」并点右下角一键复制发给我，也可以直接回复编号和感觉。
```

## 三、候选元数据：`source-manifest.md`（多轮/正式项目按需）

可在 HTML 内嵌同名 JSON 数组，或同步输出为 Markdown 便于追溯：

```markdown
### I001 · <作品或项目名>
- **本地预览 / 原项目链接**：`assets/I001.jpg` | <URL>
- **作者 / 年份 / 信源**：<未知项标未知>
- **关联词与搜索语**：`W01` · `risograph editorial poster`
- **视觉特征（Agent 初判）**：单墨粗网点 + 大字标题压边
- **状态**：`候选` / `Agent 推荐` / `用户已选` / `已折叠（原因）`
- **用户原话**：<未反馈留空>
- **系列图 / 细节**：<如有>
```

## 四、方向沉淀：`moodboard.html` / 情绪板说明结构

每个独立方向复用以下结构（以大图与系列关系为主，文字精炼）：

```markdown

- **一句话气质**：
- **判断依据**：来自用户选图 `I004`、`I012` 及讨论结论（若为 Agent 代选，在此明示）

## 核心参考与手法拆解
- **主导参考**（`I004`）：<最关键的 1–2 个视觉手法，如字图关系/留白比例>
- **辅助参考与细节**（`I012`、`I019`）：<补充的材质/色彩/系列延展>
- **Agent 补充桥梁参考**（如有，标明用途）：

## 对本项目的转化
- **保留并转化**：
- **明确避开**：
- **仍待试样验证**：

## 完整回看入口
- 候选图库：`image-selection.html` · 探索记录：`notes.md`
```

## 五、状态总表：`decision.md`（持续多轮项目按需）

最新结论永远置顶，历史记录按轮次向下追加：

```markdown

## 当前状态（最新）
- **已确定**：<范围、依据与对应产物>
- **比较中**：<待决方向与对照入口>
- **已放弃**：<方向与原因>
- **下一轮要解决**：

## 历史轮次
- **Round 2（日期）**：...
- **Round 1（日期）**：...
```
